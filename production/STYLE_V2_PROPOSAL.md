## Структура ролика
1. Хук в первые 1,5 с: самая сильная фраза. Лицо в кадре + низкий удар.
2. Ценность: каждая смысловая фраза подкреплена своим кадром (товар, деталь, текстовая карточка).
3. Подтверждение: реальные изделия крупно, со светом и движением.
4. Эмоциональный финал: лучший дубль с взглядом в камеру.
5. CTA + финальная карточка Hidjaz Premium (2,5–3 с).
Длина — по материалу, без растягивания (обычно 20–40 с).

## Выбор дублей
- Расшифровать весь исходник с таймкодами. Найти все дубли каждой фразы.
- Сравнить каждый дубль по метрикам: совпадение с текстом, темп, паузы, диапазон интонации, уверенность распознавания, взгляд в камеру. Выбор и причины фиксировать в REPORT.
- Сокращать колебания длиннее ~0,4 с, естественные паузы оставлять. Не склеивать одно предложение из разных дублей, если можно обойтись одним.

## Картинка
- Спикер в кадре 30–40 % времени. Два плана со спикером подряд не ставить: между ними B-roll.
- Средняя длина плана 1,5–3 с. На планах со спикером кроп до 1,25×.
- B-roll только из разрешённых материалов: реальные кадры товара (медианная подложка, кадрирование, перевод фокуса, медленный наезд/проезд, световой блик, золотая пыль, зерно), досъёмки владельца, лицензированный сток. AI-генерация — только с разрешения и никогда не изображает сам товар.
- Тёплый кинематографичный грейд, виньетка, лёгкое зерно, единый для всех планов.

## Типографика
- Субтитры: Inter Black, ЗАГЛАВНЫЕ, 84 px на 1080×1920, 1–3 слова. Одно ключевое слово золотом `#F2C13D`, «поп» 110 мс. Нижняя треть (y≈1480), не больше 2 строк, поля ≥ 60 px.
- Старт субтитра — по реальному началу речи (волна), не по ASR.
- Плашки-теги сверху (y≈330): золотой фон, чёрный Inter Black 52 px.
- Текстовые карточки: Inter Black 150–170 px на бархате со светом или на размытом товаре.
- Бренд: Cormorant Garamond SemiBold, золото.
- Правописание: нормализованное («Коран»). Сомнительные слова отмечать в отчёте.

## Звук
- Голос естественный: срез ниже 70 Гц, лёгкий EQ, деэссер ≤ 0,2, компрессор 2:1. Шумодав только при реальном шуме.
- Выравнивание уровня по фразам (разброс ≤ 1 LU), итог −14 LUFS линейно, пик ≤ −1 dBFS.
- Атмосфера: собственный синтез или лицензированные эффекты, на 18–30 дБ ниже голоса. Без громких переходных звуков. Музыка только с разрешения и лицензией.

## Проверка перед выдачей
Раскадровка каждые 0,5 с и кадр после каждой склейки; повторное распознавание итогового звука; ffprobe/декодирование/loudness/blackdetect; сравнение с референсом по темпу и разнообразию; выдача по DELIVERY_RULES.
